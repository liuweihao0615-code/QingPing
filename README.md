# 清屏（QingPing）Android

清屏是一个基于 Android AccessibilityService 的开屏广告线索识别原型，包含本地关键词规则管理与按应用统计。

## 当前功能

- 开关疑似广告识别
- 添加、删除关键词规则（默认：广告、sponsored、advertisement、跳过、skip）
- 按应用包名加入/移出忽略列表
- 按应用统计疑似广告线索次数
- 清空本地统计
- 所有设置和统计保存在本机 SharedPreferences

## 重要限制

- 统计记录的是**疑似广告线索事件**，不等于成功拦截或关闭广告。
- 规则匹配依赖其他应用通过无障碍接口暴露的文本；图片广告、受保护界面和部分应用可能无法识别。
- 当前不会自动点击、跳过或返回，避免误触和破坏正常操作。
- 当前没有数据库云同步、开机自启、前台常驻服务或对所有手机型号的兼容性保证。
- 无障碍服务必须由用户在系统设置中手动启用。

## 构建 APK

1. 打开仓库的 Actions 页面。
2. 进入最新的 Build QingPing APK 工作流运行记录。
3. 等待任务显示成功，然后在 Artifacts 中下载 QingPing-debug-apk。
4. 解压后取得 app-debug.apk 并传到 Android 手机安装。

也可以用 Android Studio 打开仓库根目录并执行 Build > Build Bundle(s) / APK(s) > Build APK(s)。

## 首次使用

1. 安装并打开清屏。
2. 打开无障碍设置，手动启用“清屏广告识别服务”。
3. 在清屏首页打开“启用疑似广告识别”。
4. 根据实际使用情况维护关键词和忽略应用包名。
5. 在“疑似广告统计”中查看每个应用的线索事件计数。

统计和规则仅保存在本机；卸载应用或清除应用数据后可能丢失。
